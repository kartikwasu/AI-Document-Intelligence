
# AI Document Intelligence & Enterprise Knowledge Assistant

## Project Overview
An AI-powered document assistant that allows users to upload documents and ask questions based on their content.

## Problem Statement
Organizations store large amounts of information in PDF documents. Finding relevant information manually is time-consuming.

## Objectives
- Upload and process PDF documents.
- Extract and divide text into chunks.
- Generate embeddings.
- Store document vectors in a vector database.
- Retrieve relevant information using RAG.
- Generate answers using an LLM.
- Display answers with document references.

## Technology Stack
- Python
- LangChain
- Groq API
- ChromaDB
- FastAPI
- Streamlit
